Conecta el MCP a tu agente

Las mismas cuatro herramientas, con tu modelo y sin coste para nadie más
POST https://datosabiertos.sejas.es/mcp · Streamable HTTP · JSON-RPC 2.0 · sin autenticación · solo lectura

  1. Registra el servidor (una vez; --scope user para tenerlo en todos tus proyectos):

    claude mcp add --transport http --scope user datosabiertos https://datosabiertos.sejas.es/mcp

  2. Comprueba que conecta:

    claude mcp list
# datosabiertos: https://datosabiertos.sejas.es/mcp (HTTP) - ✔ Connected

  3. Abre claude y pregunta. Dentro de la sesión, /mcp muestra las herramientas. Para usarlo sin confirmación en modo no interactivo:

    claude -p --allowedTools "mcp__datosabiertos__*" "¿Qué publica Córdoba sobre presupuestos y con qué licencia?"

Probado con Claude Code 2.1: conecta, lista las cuatro herramientas y las llama sin ningún ajuste.

  1. Añade el servidor (Codex CLI ≥ 0.20 admite servidores streamable HTTP con --url):

    codex mcp add datosabiertos --url https://datosabiertos.sejas.es/mcp

  2. O escríbelo a mano en ~/.codex/config.toml; es exactamente lo que genera el comando anterior:

    [mcp_servers.datosabiertos]
url = "https://datosabiertos.sejas.es/mcp"

  3. Comprueba con codex mcp list (no hace falta codex mcp login: el servidor no pide credenciales) y pregunta desde codex.

Verificado con Codex CLI 0.154: el comando registra el servidor como streamable_http.

Claude Desktop habla con servidores locales por stdio. El puente mcp-remote (necesita Node.js ≥ 20) convierte este servidor remoto en uno local.

  1. Abre Settings → Developer → Edit Config y añade el servidor a claude_desktop_config.json:

    {
  "mcpServers": {
    "datosabiertos": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://datosabiertos.sejas.es/mcp", "--transport", "http-only"]
    }
  }
}

  2. Reinicia Claude Desktop. Las herramientas aparecen en el menú de conectores de la conversación.

  3. Si prefieres no depender de Node, clona el repositorio y usa el transporte stdio nativo (Python 3.11, sin pip install):

    {
  "mcpServers": {
    "datosabiertos": {
      "command": "python3",
      "args": ["-m", "tfm.mcp"],
      "cwd": "/ruta/a/datosabiertos"
    }
  }
}

  1. Cursor — .cursor/mcp.json en el proyecto (o ~/.cursor/mcp.json para todos):

    {
  "mcpServers": {
    "datosabiertos": { "url": "https://datosabiertos.sejas.es/mcp" }
  }
}

  2. VS Code (Copilot) — .vscode/mcp.json:

    {
  "servers": {
    "datosabiertos": { "type": "http", "url": "https://datosabiertos.sejas.es/mcp" }
  }
}

  3. Gemini CLI:

    gemini mcp add --transport http datosabiertos https://datosabiertos.sejas.es/mcp

Cualquier cliente que admita el transporte Streamable HTTP sin autenticación vale. Si el tuyo solo habla stdio, usa el puente mcp-remote de la pestaña de Claude Desktop.

  1. Lista las herramientas:

    curl -s https://datosabiertos.sejas.es/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

  2. Llama a una:

    curl -s https://datosabiertos.sejas.es/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"buscar_datasets","arguments":{"consulta":"calidad del aire","ciudad":"malaga","limite":3}}}'

  3. Estado del índice:

    curl -s https://datosabiertos.sejas.es/salud

Un primer prompt para probarlo

Pide explícitamente la cita y la licencia: es lo que distingue una respuesta comprobable de una inventada.

Usa las herramientas de datosabiertos para responder: ¿qué datos abiertos publica Málaga sobre calidad del aire? Para cada dataset dame el título, la url_origen tal cual la devuelve la herramienta, la fecha de modificación y si el portal declara licencia. Si no hay resultados, dilo sin inventar nada. Después compara con Madrid usando comparar_ciudades.
Herramientasbuscar_datasets · detalle_dataset · listar_distribuciones · comparar_ciudades
ProcedenciaCada ficha lleva url_origen, fecha_sincronizacion y licencia_declarada.
AusenciasSin resultados no es una lista vacía: es un campo sin_resultados que pide no inventar.
LímitesSin SSE ni sesiones; sin cuota más allá del sentido común. Es un prototipo de TFM.

Procedencia. Los metadatos son una copia de los portales municipales, no la fuente viva: cada resultado lleva su url_origen y la fecha de sincronización. Los datasets cuyo portal no declara licencia salen marcados como licencia no declarada; no se asume que sean abiertos.

Privacidad. El motor «Servidor» envía tu conversación a OpenRouter y al proveedor del modelo (Meta, nivel contributor, cuyas condiciones permiten usar las peticiones para entrenamiento). El motor «Tu navegador» no envía nada a ningún sitio. La búsqueda directa tampoco. No hay cuentas ni cookies.
